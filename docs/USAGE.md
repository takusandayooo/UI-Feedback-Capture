# 使い方

[紹介へ戻る](../README.md) · [セットアップ](SETUP.md) · [開発ガイド](DEVELOPMENT.md)

## 要素にコメントする

1. 拡張アイコンを押し、変更したい要素をクリックする。
2. 枠の下、または空きのある上側に表示される欄へ修正内容を入力する。
3. 「要素を追加」で別の場所を選び、コメントを続ける。
4. 「完了」で一覧へ戻り、「プロンプトをコピー」で全件をまとめて取り出す。

コメント欄はスクロールやサイズ変更に追従し、一覧・下書きと同期します。Escで選択やその場の入力を終了できます。入力済みのコメントは保持します。日本語の変換中は、Escで欄を閉じません。

一覧のペンボタンで対象のそばに戻って編集できます。カードにマウスを重ねると、ページ上の対象要素に枠を表示します。「要素」を開くと、HTMLまたは対象要素のPNGを保存できます。PNGは保存時の表示を撮影し、画面より大きい要素はスクロールしてつなぎ合わせます。

HTMLではフォームの入力内容を除外します。古い下書きのHTMLが抜粋の場合、全文を保存するには要素を選び直します。

## 画像に書き込む

「画像に書き込む」で表示範囲またはページ全体を選び、撮影します。ペン・囲み・矢印で書き込み、「完了」で添付します。画像はコピー、またはPNG保存してAIへ渡します。画像データはテキストのプロンプトとは別に添付します。

画像編集画面の上部でも撮影範囲を切り替えられます。書き込みがある場合は、消去前に確認します。画像のコメントは保持します。撮影失敗やEscによる中断では、元の画像と書き込みを保持します。

ページ全体の撮影はドキュメントのスクロール領域が対象です。独立した内部スクロール領域、無限スクロール、撮影中に高さが変わるページでは、全体を撮影できない場合があります。固定・追従要素は最初の画像にだけ表示します。撮影中は対象タブを開いたままにしてください。

撮影の上限は100タイル・64百万画素・一辺32760pxです。

## 音声入力

コメント欄の「音声」を押し、マイクを許可して日本語で話します。聞き取り中のテキストを表示し、確定した結果をコメントに追加します。「停止」で録音を終了します。ページを閉じたり、入力をキャンセルした場合も認識を終了します。

ブラウザーの `SpeechRecognition` / `webkitSpeechRecognition` を使用し、言語は `ja-JP` です。モデル選択・ダウンロード・WebGPUは不要です。対応していないブラウザーでは音声ボタンを無効にします。

音声はブラウザーの認識サービスへ送信される場合があります。ChromeとOSのマイク許可、およびインターネット接続が必要です。認識結果は確認してからコピーしてください。

## 保存とプライバシー

下書きはURLごとにChromeのローカルストレージへ保存します。メニューから「このページの下書きを削除」を実行できます。大きな添付画像は保存容量に達する場合があるため、コピーまたはPNG保存で取り出してください。

ページや画像には個人情報が含まれることがあります。外部のAIへ貼り付ける内容は、コピー後も確認できます。データの取り扱いは[プライバシーポリシー](../public/privacy.html)へ。
