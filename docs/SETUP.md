# セットアップ

[紹介へ戻る](../README.md) · [使い方](USAGE.md) · [開発ガイド](DEVELOPMENT.md)

## ソースから準備する

ChromeとBunを用意し、プロジェクトのルートで実行します。開発時の確認環境はBun 1.4.2です。

```sh
bun install --frozen-lockfile
bun run build
```

実行用のファイルが `dist/` に作成されます。コードの編集方法は[開発ガイド](DEVELOPMENT.md)を参照してください。

## Chromeに読み込む

1. Chromeで `chrome://extensions` を開く。
2. 「デベロッパーモード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」から `dist/` を選ぶ。
4. 拡張機能をツールバーに固定し、通常のウェブページでアイコンを押す。
5. 変えたい要素をクリックし、枠のそばに表示される欄へコメントを入力する。

配布用ZIPを使う場合は、展開して `manifest.json` が入っているフォルダーを選びます。実行用ZIPではBunやビルドは不要です。

更新したときは、拡張機能の再読み込みボタンを押し、対象のウェブページも再読み込みします。以前からプロジェクト直下を読み込んでいる場合も、ビルドで直下の実行ファイルを更新します。

## 音声入力を使う

コメント欄の「音声」を押し、マイクを許可して話します。同じ画面のまま入力でき、モデルの取得は不要です。停止する場合は「停止」を押します。

Chromeの音声認識サービスを利用するため、インターネット接続が必要です。音声がブラウザーの認識サービスへ送信される場合があります。HTTPSまたはlocalhostのページで利用してください。

## 起動・入力できないとき

| 状況 | 確認すること |
| --- | --- |
| 拡張アイコンを押しても起動しない | Chromeの管理画面やウェブストア等の保護されたページでは使えません。通常のウェブページで試します。 |
| 修正が反映されない | ビルド後、拡張機能と対象ページの両方を再読み込みします。 |
| マイクを使えない | ChromeとOSのマイク設定を確認します。 |
