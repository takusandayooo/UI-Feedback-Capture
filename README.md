**ウェブページの要素を選び、コメントと画像をまとめてAIに渡せるChrome拡張です。**

「この見出しを大きく」「この余白を半分に」。変えたい場所をクリックして、その場で入力します。複数の指示をまとめてコピーすると、対象のHTML・CSS・位置も一緒に伝えられます。

<p align="center">
  <img src="docs/images/inline-comment.png" width="760" alt="選んだ見出しを枠で囲み、そのすぐ下に変更内容を入力するコメント欄">
</p>

画面は動作確認用のページです。

## できること

- **場所を選んで伝える** — 要素の枠の上・下でコメントを入力。一覧からも編集できます。
- **まとめてAIへ渡す** — 複数の修正指示を、要素情報付きのプロンプトとして一括コピー。
- **画像に描いて伝える** — 表示範囲・ページ全体を撮影し、ペン・囲み・矢印で書き込み。
- **日本語を話して入力する** — ブラウザー標準の音声認識で入力。

コピーした指示と画像を、普段使っているAIに貼り付けて使います。
